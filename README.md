# 🐦 Claude Session Pets

실행 중인 **Claude CLI 세션을 감시해, 세션마다 작은 데스크탑 펫을 띄우는** macOS 앱.
각 펫이 자기 세션의 상태(작업 중 · 입력 필요 · 완료)와 **지금 하고 있는 작업**을 말풍선으로 보여줍니다.

> Electron 기반. 화면 위를 돌아다니는 투명 오버레이라 다른 작업을 방해하지 않습니다.
> 메인펫은 어른새, 세션마다 뜨는 작은 펫은 그 아기새입니다(둘 다 원하는 이미지로 교체 가능).

### 세션 폼 (입력이 필요할 때 펫이 폼을 띄움)

세션에서 **`/session-form on`** 을 한 번 치면, 이후 클로드가 사용자 확인·선택·입력이 필요할 때(리뷰 결과 승인, 방안 선택 등)
인라인으로 묻는 대신 **입력 폼**을 만들어 그 세션의 펫에 📋로 띄웁니다. 폼을 채워 **전송**하면 그 답을 세션에 되돌려 작업을 이어갑니다.
(`/session-form off` 로 끔.) 폼은 `<프로젝트>/docs/form/`에 남습니다.

## 요구 사항

- **macOS** (패키징된 `.app`은 Apple Silicon/arm64. 소스 실행은 Intel/ARM 모두 가능)
- **Node.js** 18+ 와 npm
- **Claude CLI** (Claude Code) — 감시 대상
- **python3** — 상태 훅에 사용(선택. 없으면 트랜스크립트/CPU로 폴백)

## 설치 & 실행 (소스)

```bash
git clone <레포 URL> claude-session-pets
cd claude-session-pets
npm install
npm start          # 또는 ./start.sh (백그라운드 실행 + 중복 방지)
```

- `./start.sh` 는 최초 실행 시 `npm install` 후 백그라운드로 띄우고, 이미 떠 있으면 중복 실행하지 않습니다. 로그: `/tmp/claude-session-pets.log`
- 종료: 펫 클릭 → ⚙️ 설정 → 앱 종료, 또는 메뉴바 발바닥 아이콘 → 종료.

### `.app`으로 설치 (독에서 실행)

`build-app.sh` 하나로 빌드부터 설치까지 끝납니다:

```bash
./build-app.sh            # .app 빌드 → /Applications 설치 → 실행
./build-app.sh --no-open  # 설치까지만 (실행은 안 함)
./build-app.sh --build    # dist/에 빌드만 (설치 안 함)
```

내부적으로 `electron-packager` 빌드 → 아이콘 교체 → ad-hoc 재서명 → 구버전 휴지통 이동 → `/Applications` 설치를 자동으로 수행합니다. 전체 절차와 다른 맥 배포 방법은 [`CLAUDE.md`](CLAUDE.md)의 **패키징** 섹션 참고. 앱은 `app.dock.hide()`를 호출하므로 실행 중 독에 아이콘이 보이지 않습니다(독 등록은 Finder에서 드래그).

## 사용법

### 메인 펫
- **배회** — 화면 하단(독 위)을 걸어다니고, 쉬고, 가끔 잠도 잡니다.
- **집어서 옮기기** — 드래그하면 대롱대롱 매달리고, 놓으면 중력으로 떨어져 착지합니다.
- **클릭 → 패널**
  - **🗣️ 명령** — 작업 폴더 지정 후 프롬프트 입력(⌘+Enter) → `claude -p`로 실행, 출력이 실시간 스트리밍. 여러 세션 동시 실행/중단 가능.
  - **📋 Claude 목록** — 이 PC에서 실행 중인 **모든** Claude CLI 프로세스 표시(작업 폴더 · PID · CPU · 경과시간 · 상태). 개별 종료, 그리고 **실행 중 세션의 터미널에 프롬프트 직접 입력**(해당 tty의 iTerm2/Terminal 탭을 AppleScript로 찾아 타이핑) 가능.
  - **⚙️ 설정** — 펫 이미지 변경, 크기, 좌우 반전, 배경 자동 제거 토글.

### 세션 펫
실행 중인 다른 Claude CLI 세션마다 작은 펫이 하나씩 떠서 돌아다닙니다.
- 이름은 세션 작업 폴더의 최하위 디렉토리명, 머리 위 뱃지는 전체 프로세스 수.
- **작업 시작** → `🏃 {현재 작업}` 말풍선 (도구 호출마다 "파일명 수정 중", "테스트 실행" 등으로 갱신). 작업 중엔 클릭/드래그해도 말풍선 유지.
- **입력 대기** → `🙋 입력 필요!` (갸웃거리며 클릭할 때까지 유지).
- **완료** → `🎉 작업 완료!` + 방방 뛰는 모션 (클릭하거나 다음 작업 시작 전까지 유지).
- **세션 종료** → `👋 안녕~` 하고 사라집니다.
- **우클릭 메뉴** — 창 앞으로 가져오기(그 세션의 IntelliJ/VS Code/iTerm/Terminal 창을 맨 앞으로) · 이미지 변경 · 좌우 반전 · 기본 모습으로.
- **개별 이미지** — 더블클릭 또는 드래그&드롭. 작업 폴더 경로 기준으로 저장돼 재시작해도 유지.

### 커스텀 캐릭터
아무 이미지나 넣으면 펫이 됩니다. 단색 배경은 자동 제거 + 여백 트림(PNG 투명 배경은 그대로), 걷기/숨쉬기/드래그/착지 애니메이션이 자동 적용됩니다.

## 동작 방식

- **투명 오버레이** — 항상 위, 전체 화면 크기 창. 펫/패널 위가 아닐 땐 마우스가 완전히 통과합니다.
- **프로세스 감지** — `ps` 출력에서 Claude CLI만 필터링(데스크탑 앱 제외), `lsof`로 각 세션의 작업 폴더 조회. 1초마다 갱신.
- **작업 중 / 유휴 판정 (정확도 순 3단 폴백)**
  1. **상태 훅** (가장 정확) — Claude Code 생명주기 훅이 세션별 상태 파일 `~/.claude/session-pets-status/<session_id>.json`을 직접 기록. `UserPromptSubmit`→작업 중, `Stop`→유휴, `Notification`→입력 필요, `SessionEnd`→종료. 세션 id로 프로세스와 정확히 매칭. 도구 호출(`PreToolUse`)마다 현재 작업 요약도 기록.
  2. **트랜스크립트** — 훅이 없는(설치 전 시작된) 세션은 `~/.claude/projects/<인코딩된 cwd>/*.jsonl`의 마지막 turn 경계(`tool_use`=진행 중, `end_turn`=유휴) + mtime으로 판정.
  3. **CPU 시간** — 위 둘 다 없으면 누적 CPU 시간 증가로 폴백.
- **명령 실행** — `claude -p --output-format text`를 지정 폴더에서 spawn, stdout/stderr를 패널로 스트리밍.
- **tty 주입** — 실행 중 세션의 tty를 찾아 AppleScript로 해당 터미널 탭에 타이핑(iTerm2/Terminal.app. tmux/VS Code 터미널 미지원, 최초 사용 시 자동화 권한 필요).

### 상태 훅 설치
가장 정확한 감지를 위해 첫 실행 시 **훅 설치 여부를 물어봅니다**. 승인하면:
- `~/.claude/session-pets-hook.py` 헬퍼 설치
- `~/.claude/settings.json`에 생명주기 훅 병합 (기존 설정은 `settings.json.session-pets-backup`으로 백업)
- **새로 시작하는 세션부터** 적용 (이미 실행 중인 세션은 트랜스크립트로 감지)
- 메뉴바 아이콘에서 언제든 재설치/제거 가능

## 파일 구조

| 파일 | 역할 |
|---|---|
| `main.js` | Electron 메인 — 창/트레이, 프로세스 조회(ps/lsof), 훅 설치, tty 주입, `claude -p` 실행, 이미지 저장 |
| `preload.js` | IPC 브릿지 |
| `pet.html` | 펫 + 패널 마크업/CSS(애니메이션 keyframes 포함) |
| `pet.js` | 렌더러 — 메인/세션 펫 상태머신(배회·드래그·낙하), 말풍선, 배경 제거(flood fill), 패널 로직 |
| `start.sh` | 개발용 백그라운드 실행 스크립트 |
| `build/icon.icns` | 앱 아이콘 (어른새) |
| `CLAUDE.md` | 개발/패키징 가이드 (기여 시 참고) |
